---
title: Contribute
---

Corrections, original case studies, and new risk patterns are welcome after the repository is public.

1. Open a GitHub issue describing the missing pattern or inaccurate claim.
2. Follow the [data model](https://github.com/eyeinthesky6/india-fintech-risk-atlas/blob/main/docs/DATA_MODEL.md) and [research protocol](https://github.com/eyeinthesky6/india-fintech-risk-atlas/blob/main/docs/RESEARCH_PROTOCOL.md).
3. Submit a pull request with original writing and links to primary sources.
4. A reviewer checks each regulatory claim, entity scope, date, counterexamples and citation.

Contributors should not modify the site UI in content-only pull requests.
