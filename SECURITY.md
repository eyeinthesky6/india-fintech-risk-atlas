# Security Policy

## Reporting Security Vulnerabilities

The India Fintech Risk Atlas takes security and data privacy seriously. If you discover a vulnerability or potential exposure in the website infrastructure, Cloudflare triage workers, or automated ingestion scripts, please report it responsibly.

### What to Report:
- Credential or API secret leaks.
- Vulnerabilities in Cloudflare triage workers or GitHub Actions workflows.
- Web vulnerabilities (e.g. Cross-Site Scripting, prototype pollution, CORS bypass) on the public website.
- Tampering or injection vectors in automated RSS feed parsers.

### How to Report:
- **Private Reporting:** Open a [GitHub Security Advisory](https://github.com/eyeinthesky6/india-fintech-risk-atlas/security/advisories/new) (preferred) or email the maintainers directly at `security@six.tech`.
- Please include:
  - Description of the vulnerability.
  - Steps to reproduce or proof-of-concept.
  - Potential operational impact.

### Response Timelines:
- **Initial acknowledgment:** Within 48 hours.
- **Triage & Remediation:** Critical issues will be patched and deployed within 7 business days.

*Note: For reporting factual inaccuracies, outdated circulars, or missing entity carve-outs in Atlas records, please use the [Factual Correction Issue Form](https://github.com/eyeinthesky6/india-fintech-risk-atlas/issues/new?template=factual-correction.yml).*
